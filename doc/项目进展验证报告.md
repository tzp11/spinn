## 一、项目概况

**SPINN** (Spaceborne Portable Inference Neural Network) 是面向星载嵌入式平台的轻量级神经网络推理框架。

### 核心目标
- 紧凑的模型格式（ENNF）替代 ONNX
- 静态内存规划，零动态分配
- 源码转译，支持异构交叉编译
- 零外部依赖（仅 libc/libm）

### ✅ 2.4 M_max 内存上限约束（创新点2扩展）

**状态**: **已完成**

```c
int spinn_plan(SpinnContext *ctx, uint32_t max_arena_bytes);

// spinn_memory_planner.c
int spinn_plan_memory(SpinnContext *ctx, uint32_t max_arena_bytes) {
    free_list_init(max_arena_bytes);  // 以 M_max 为上界初始化
    // ...
}
```

#### 命令行支持
```bash
./spinn_run model.ennf --max-arena=4M
```

**功能**:
- `max_arena_bytes = 0`: 无限制模式
- `max_arena_bytes > 0`: 受限模式，分配失败时提前报错
- 可在部署前判断模型是否满足平台内存约束
