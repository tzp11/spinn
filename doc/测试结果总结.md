## 一、测试概览

本次测试对比了三种推理方案在 MNIST、YOLOv10n、ResNet101 三个模型上的表现：

1. **ONNX Runtime (Python)** - 业界标准推理框架
2. **SPINN Runtime (C)** - 本项目的运行时引擎
3. **Generated C (ennf2c)** - 本项目的源码转译方案

测试指标：
- ✅ 推理时间（Best/Avg）
